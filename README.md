# Autocomplete Search Engine (Trie + Top-K Suggestions)

## Project Overview
This project implements an **interactive autocomplete search engine** using **Trie data structures** combined with **frequency-based top-k suggestions**. As the user types in the search bar, the app dynamically suggests the most relevant words, similar to Google’s search autocomplete.

Key features:

- **Trie-based storage**: Efficiently stores all dictionary words for fast prefix search.
- **Frequency tracking**: Frequently searched words are prioritized.
- **Top-K suggestions**: Only the most relevant words are suggested for performance and clarity.
- **React Frontend**: Interactive UI with highlighted matches and click-to-select functionality.
- **Scalable**: Can handle thousands of words efficiently.
